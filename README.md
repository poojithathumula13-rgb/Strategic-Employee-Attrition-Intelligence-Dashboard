# Strategic-Employee-Attrition-Intelligence-Dashboard
This is my first individual Power BI project, focused on analyzing employee attrition and understanding the factors associated with employees leaving an organization.

The project uses data from 5,000 employees, of which 895 employees have left, resulting in an overall attrition rate of 17.9%.

The dashboard analyzes factors such as salary growth, overtime, burnout, engagement, work mode, performance, career level, department, and job role.

🛠️ Tools Used

Power BI | Power Query | DAX | CSV

🎯 Project Goal

To transform employee data into meaningful visual insights and understand employee attrition patterns to support better retention decisions.
